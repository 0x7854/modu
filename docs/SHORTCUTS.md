# 在 iPad / iPhone 上「用墨读打开」

从“文件”App 或其他能分享文件的 App 中选择 Markdown 或单文件 HTML，轻点“分享”，运行“用墨读打开”。快捷指令将文档上传到你自己的墨读云文库，成功后提示“已加入墨读”，不会自动打开浏览器。点开主屏幕的墨读图标即可阅读；Mac 的云端文库也能看到它。

## 首次设置

1. 在浏览器登录自己的墨读，打开左侧文库中的“快捷指令”设置。
2. 生成“仅导入凭证”，复制保存。它只在生成时显示；遗失后可重新生成，旧凭证随即失效。
3. 下载并添加“用墨读打开”快捷指令，按安装提示填入服务网址和仅导入凭证。
4. 首次运行时，按系统提示允许快捷指令访问你配置的服务网址。

已安装的旧快捷指令不会自动更新。可在 iPad 编辑旧指令，把成功分支里的“打开 URL”删除，保留上传和错误提示；也可以重新下载本模板并填入原有配置。

如需修改配置，在快捷指令编辑界面更改最前面的两个“文本”操作：服务网址、仅导入凭证。

不要填入网页登录密码或 Mac 同步令牌。公开下载的模板不包含任何凭据；配置后的快捷指令只供自己使用，不要直接分享给别人。要分享请发送未配置的通用模板链接。

保存按钮优先弹出系统分享面板，可取消并留在墨读。选择“存储到文件”，再从“文件”打开安装；不支持此文件分享的设备会提供复制下载链接，请粘贴到 Safari 地址栏打开。墨读不会导航到系统文件预览。若旧版已卡在预览，可从多任务界面关闭墨读，再从主屏幕图标重新打开。

## 日常使用

- 在“文件”中长按一个 `.md`、`.markdown`、`.html` 或 `.htm` 文件，选择“分享 → 用墨读打开”。
- 如未显示，可以在分享菜单中寻找“编辑操作”，或确认快捷指令详情已开启“在共享表单中显示”。
- 也可以在墨读网页内点“导入文档”，从系统文件选择器直接选择 MD。

阅读页可能在 Safari 打开；如尚未登录，登录后继续阅读。它不保证直接跳到主屏幕上的独立网页窗口。

## 数据如何处理

- 文档上传到你设置的服务器，默认放在“未归档”。
- HTML 后缀会保留；文件名无后缀或以 `.txt` 结尾时，只有正文明确为完整 HTML 文档才保存为 `.html`，其他文本保存为 Markdown。正文不改写。已有 `.md` / `.markdown` 后缀不会重复添加，原文件不改名。
- 同名文件不自动合并，不会覆盖 Mac 上的原文件。再次运行分享会创建另一份文档。
- Mac 可从云文库阅读；此功能不自动把新文档写进 Mac 某个本地目录，也不提供正文双向编辑。
- 仅导入凭证不能读取、覆盖或管理已有文档。可在网页中撤销；修改账号密码后旧凭证也会失效。
- 支持单个 Markdown 或 HTML 文件，默认最大 2 MiB。不随文档上传外置图片、CSS 或脚本；HTML 保持原有 iframe 沙箱。旧快捷指令上传的正文如果保留完整 HTML 源码，也可识别；若来源 App 只分享了可见文字，需要保存原始 HTML 文件后重新导入。

## 排查

- **“如果”显示空条件或“请为此操作中的每个参数选取值”**：旧模板的条件变量格式错误，2026-11-15 已修正。重新下载并替换旧版，服务网址和仅导入凭证沿用原配置；遗失凭证时在网页重新生成。

- **凭证无效**：在网页重新生成仅导入凭证，再更新快捷指令设置。
- **文件格式不支持**：确认传入的是 Markdown 或 HTML 文件本身，而不是网页链接、文件夹或 PDF。
- **正文过大**：拆分后导入；不要只修改扩展名绕过格式限制。
- **网络请求失败**：确认服务网址包含 HTTPS、服务可访问，再重试。
- **上传成功但阅读要求登录**：上传凭证与阅读登录相互独立，请正常登录墨读。

开发接口：`POST /api/import/documents`，JSON 字段为 `name`、`content` 和可选 `kind`、`requestId`；兼容旧快捷指令的 `markdown` 正文字段（不要同时提交两个正文字段）。`kind` 可为 `markdown` 或 `html`，须与文件名一致。可选 `requestId`（32 位小写十六进制）。快捷指令使用 `Authorization: Bearer <仅导入凭证>`；网页使用登录 Cookie 和 CSRF。响应的 `url` 是本站相对阅读地址。生产系统应使用 HTTPS。

苹果参考：[从其他 App 运行快捷指令](https://support.apple.com/zh-tw/guide/shortcuts/apd163eb9f95/9.0/ios/26)、[通过快捷指令请求 API](https://support.apple.com/en-lamr/guide/shortcuts/apd58d46713f/ios)。
