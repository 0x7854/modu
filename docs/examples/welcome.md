# 给阅读留一点空间

一份文档，可以从工作台走到沙发，也可以从正在生成的草稿变成随手可看的资料。

## 今天的阅读清单

- [x] 看完项目说明
- [ ] 整理一个值得继续追问的问题
- [ ] 把需要保留的资料加入云端文库

## 跟着变化一起读

用任意编辑器或 Agent 修改这份 Markdown，保存后，墨读会更新正在显示的正文。

> 文档可以不断变，阅读不必反复开始。

## 工作与生活

| 场景 | 放进文库的内容 |
| --- | --- |
| 工作 | 会议记录、研究笔记、项目说明 |
| 学习 | 课程提纲、练习总结、阅读摘记 |
| 生活 | 旅行计划、食谱、预算小工具 |

## 一个小示例

```javascript
const ideas = ['阅读', '整理', '分享'];
ideas.forEach(idea => console.log(idea));
```

所有示例均为虚构演示，不包含真实业务资料。
